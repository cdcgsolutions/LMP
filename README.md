# Letras Mi Poblau (LMP)

**Letras Mi Poblau (LMP)** es una plataforma web y archivo digital interactivo de preservación folklórica y musical beniana, desarrollado para el **Instituto de Formación Artística "Edelmira Limpias" (IFAEL)** en Trinidad, Beni - Bolivia.

---

## 🌟 Características Principales

- **Cancionero y Letras Interactivas:** Visualizador de letras con acordes musicales integrados, transposición tonal en semitonos y función de auto-scroll para acompañamiento en vivo.
- **Visor de Partituras y Manuscritos:** Consulta de partituras digitalizadas del archivo documental del IFAEL con zoom interactivo y opciones de descarga/impresión.
- **Reproductor de Muestra Folklórica:** Reproductor continuo de audio con sintetizador Web Audio API, visualizador de ondas en tiempo real y controles de volumen/repetición.
- **Explorador de Géneros y Ritmos Benianos:** Guía descriptiva de Taquirari, Chovena, Carnavalito y Danza de Macheteros con sus patrones rítmicos e instrumentación tradicional.
- **Perfiles Comunitarios e Institucionales:** Espacios de biografía de artistas e información académica del IFAEL.
- **Modo Oscuro / Claro:** Soporte completo de temas con persistencia en almacenamiento local.

---

## 🛠️ Arquitectura y Tecnologías

- **Arquitectura N-Capas:** Separación limpia de responsabilidades (Datos, Servicios, Componentes, Controlador).
- **Core:** HTML5 Semántico, JavaScript Modular (ES6+).
- **Estilos:** Vanilla CSS con variables de diseño personalizadas y diseño adaptativo (*Mobile-First*).
- **Iconografía:** Font Awesome 6.

---

## 🚀 Despliegue y Uso

Simplemente abre `index.html` en cualquier navegador web moderno o sírvelo con cualquier servidor HTTP estático (por ejemplo con Live Server en VS Code).
